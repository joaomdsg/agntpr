# Handoff: Packets Design System → Claude Code

This folder is an **Agent Skill**. Drop it into your Claude Code skills directory (e.g. `.claude/skills/packets-design/`) and Claude Code will pick up `SKILL.md` as the entry point.

## What this is
The complete Packets design system: tokens, brand rules, voice, reusable component references, and full-screen UI kit recreations of the product's two core surfaces (Console + Inspector). `readme.md` is the design guide; start there.

## About the design files
Everything here is a **design reference built in HTML/JSX** — high-fidelity, exact values (colors, px sizes, radii, tracking are verbatim from the settled designs), but not production code. Recreate the components in your codebase's environment and patterns; if none exists yet, pick the stack that fits and implement there.

## How to use it in a codebase
1. **Tokens are the contract.** `styles.css` → `tokens/*.css` define every color, size, radius, and effect as CSS custom properties. Port these first, verbatim. Never invent a new state color.
2. **Components** (`components/*/`): each has `<Name>.jsx` (reference implementation, inline styles reading the tokens), `<Name>.d.ts` (props contract), and `<Name>.prompt.md` (usage + variants). The JSX is intentionally dependency-free React — straightforward to port.
3. **UI kits** (`ui_kits/console/`): ConsoleScreen + InspectorScreen show how the primitives compose into real screens, with exact layout values (grid columns 360/1fr/340 and 252/1fr/312, panel paddings, type scale).
4. **The mark is code, not an asset.** There is deliberately no logo file — build `PacketMark` (locked spec in readme.md) wherever a mark is needed.

## Known limitation
The `*.card.html` specimen files and `ui_kits/console/index.html` load `_ds_bundle.js`, a compiled library generated by the design platform — it is not included. In a codebase, ignore those HTML files' script wiring; the `.jsx` sources are the truth.

## Fonts
IBM Plex Sans + IBM Plex Mono, loaded from Google Fonts (`tokens/fonts.css`). Self-host for production.
